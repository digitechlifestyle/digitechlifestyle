# Digitech Faceless Video System

Open-source faceless video production workflow for Digitech Lifestyle.

Website: https://digitechlifestyle.com
Channel focus: Crypto, AI, digital assets, blockchain, wallets, scams, tools, and future finance.

## Purpose

This repo folder is the production system for creating faceless YouTube videos using free or open-source tools where possible.

## Core Workflow

1. Research topic
2. Write long-form script
3. Generate voiceover
4. Generate or collect visuals
5. Assemble video
6. Create thumbnail
7. Export long video
8. Cut into Shorts
9. Upload to YouTube
10. Link back to DigitechLifestyle.com

## Folder Structure

```text
scripts/       Long-form video scripts
shorts/        Short-form scripts and clips
prompts/       AI prompts for scripts, visuals, voice and thumbnails
audio/         Voiceover files
images/        AI images, screenshots and visual assets
video/         Final long-form videos
thumbnails/    YouTube thumbnails
music/         Royalty-free music and sound effects
subtitles/     Caption/subtitle files
workflows/     Automation workflows and notes
```

## Recommended Free/Open-Source Tools

- FFmpeg for video assembly
- Python for automation scripts
- GitHub for version control
- CapCut Free for manual editing
- Canva Free for thumbnails
- ComfyUI for AI visuals
- Open-source TTS for voiceover testing
