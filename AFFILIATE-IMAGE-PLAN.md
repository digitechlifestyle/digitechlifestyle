## LivePortrait Integration

**What it does:** Animates a single still-image portrait photo into a looping animated face. Perfect for:
- Animating reviewer/author headshots for article bylines
- Creating an animated "speaking presenter" thumbnail that loops for video previews
- Bringing affiliate brand mascots to life as animated WebP

**Install location:** `/Users/joerobertson/Claude - Flowstate/LivePortrait/`

**Mac requirements:** Python 3.10+, PyTorch CPU, see `requirements_macOS.txt`

**Basic usage:**
```bash
cd '/Users/joerobertson/Claude - Flowstate/LivePortrait'
python inference.py \
  --source assets/examples/source/s9.jpg \
  --driving assets/examples/driving/d0.mp4 \
  --output-dir animations/
```

**For affiliate images:**
1. Generate a neutral portrait with Midjourney / DALL-E using the AI prompts above
2. Feed the portrait as `--source` to LivePortrait
3. Use one of the included `assets/examples/driving/` motion drivers for natural head movement
4. Export as animated WebP with ffmpeg: `ffmpeg -i output.mp4 -vf "fps=12,scale=320:-1" -loop 0 output.webp`

**Recommended output settings for web:**
```bash
# Compress animated WebP to ~80KB max
ffmpeg -i animations/output.mp4 \
  -vf "fps=10,scale=320:-1:flags=lanczos" \
  -c:v libwebp -lossless 0 -compression_level 6 \
  -q:v 75 -loop 0 -preset picture \
  sidebar-animated-presenter.webp
```

## How to Generate These Images

**Recommended free/cheap tools:**
- **Midjourney** — best for photorealistic editorial (prompts above work directly)
- **DALL-E 3** via ChatGPT — good for clean product shots and UI mockups
- **Adobe Firefly** — good for editorial photography style, commercially safe
- **Leonardo.ai** — good for tech/fintech aesthetic, free tier available
- **Ideogram** — good for clean graphic/card designs

**Animated WebP workflow:**
1. Generate static frame with AI tool above
2. Import to **Canva Pro** → animate with "breathing" or "drift" effect → export as GIF
3. Convert GIF → WebP: `ffmpeg -i input.gif -c:v libwebp -loop 0 output.webp`
Or use **EZGif.com** online (free, no install needed)
