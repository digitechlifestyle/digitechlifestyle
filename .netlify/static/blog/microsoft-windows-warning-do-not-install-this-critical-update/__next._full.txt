<p class="color-body light-text" role="button">New attack warning for Windows users</p>
<p></fbs-accordion><small>NurPhoto via Getty Images</small></figcaption></figure>
<p>A critical new warning this week, as a dangerous new browser update attacks Microsoft Windows users in the wild. As ever, this attack deploys social engineering to lure users into the simple click they’ll quickly regret. Here’s what to look for.</p>
<p><a class="embed-base color-body color-body-border link-embed embed-3" href="https://www.forbes.com/sites/zakdoffman/2025/02/22/fbis-new-iphone-android-security-warning-is-now-critical/" target="_blank" aria-label="FBI’s New iPhone, Android Warning—Is Your Data At Risk?" rel="noopener noreferrer" data-ga-track="forbesEmbedly:https://www.forbes.com/sites/zakdoffman/2025/02/22/fbis-new-iphone-android-security-warning-is-now-critical/"><span class="link-embed__info"><span class="link-embed__provider">Forbes</span><span class="link-embed__title">FBI’s New iPhone, Android Warning—Is Your Data At Risk?</span><small class="link-embed__byline">By <span class="link-embed__author">Zak Doffman</span></small></span><span class="link-embed__thumbnail-wrapper"><span class="link-embed__thumbnail allow-inline-style" style="background-image:url(https://specials-images.forbesimg.com/imageserve/66abf55129bee43b04a31eef/960x0.jpg?cropX1=423&amp;cropX2=1522&amp;cropY1=173&amp;cropY2=916)"/></span></a></p>
<p>The warning comes by way of <a class="color-link" href="https://github.com/PaloAltoNetworks/Unit42-timely-threat-intel/blob/main/2025-02-18-IOCs-for-SmartApeSG-fake-browser-update-leads-to-NetSupport-RAT-and-StealC.txt" target="_blank" rel="nofollow noopener noreferrer" data-ga-track="ExternalLink:https://github.com/PaloAltoNetworks/Unit42-timely-threat-intel/blob/main/2025-02-18-IOCs-for-SmartApeSG-fake-browser-update-leads-to-NetSupport-RAT-and-StealC.txt" aria-label="Palo Alto Networks’ Unit 42">Palo Alto Networks’ Unit 42</a>, per <a class="color-link" href="https://cybersecuritynews.com/beware-new-fake-browser-updates/#google_vignette" target="_blank" rel="nofollow noopener noreferrer" data-ga-track="ExternalLink:https://cybersecuritynews.com/beware-new-fake-browser-updates/#google_vignette" aria-label="Cyber Security News"><em data-ga-track="ExternalLink:https://cybersecuritynews.com/beware-new-fake-browser-updates/#google_vignette">Cyber Security News</em></a> which picked up on the research. The attackers have injected “malicious JavaScript” into legitimate websites that will warn users they have an outdated browser module in Chrome, Edge or Firefox and need to update.</p>
<p>“These lures,” <em>Cyber Security News</em> says, “leverage realistic branding and urgency warnings, such as ‘Critical Security Update Required’.” By downloading and running the script, the malware will fetch the NetSupport RAT code it needs to attack your PC, including an executable that enables remote device control, a library enabling data exfiltration and also Windows “Registry modification scripts for persistence,” making it hard to kill the process when it’s up and running on your machine.</p>
<p>The researchers also warn that “in recent campaigns observed on February 18, 2025, NetSupport RAT delivered a secondary payload: StealC, a credential-stealing malware.” That does exactly what is says on the tin, and hunts for key login data and bypasses.</p>
<p>The researchers warn “the SmartApeSG campaign underscores the persistent threat of social engineering coupled with fileless attack techniques. By exploiting trusted software update mechanisms and Windows internals, threat actors achieve prolonged network access while evading conventional defenses.”</p>
<p>The following mitigation strategics have been provided:</p>
<ul>
<li>“Block domains associated with SmartApeSG infrastructure (e.g., <em>poormet[.]com</em>, <em>cinaweine[.]shop</em>) using threat intelligence feeds.</li>
<li>Deploy signatures for detecting malicious JavaScript patterns (e.g., long Base64 strings, asynchronous HTTP requests).</li>
<li>Monitor for anomalous process relationships, such as <em>mfpmp.exe</em> spawning network connections or writing to <em>%APPDATA%</em>.</li>
<li>Restrict PowerShell execution policies and log script activity to identify encoded command sequences.</li>
<li>Train employees to recognize fake update lures, emphasizing that browsers auto-update and never require manual downloads.”</li>
</ul>
<p>I have warned about the threat from <a class="color-link" href="https://www.forbes.com/sites/zakdoffman/2024/02/11/google-chrome-free-upgrade-warning-samsung-galaxy-s24-pixel-android/" data-ga-track="InternalLink:https://www.forbes.com/sites/zakdoffman/2024/02/11/google-chrome-free-upgrade-warning-samsung-galaxy-s24-pixel-android/" target="_self" aria-label="fake browser installs and updates">fake browser installs and updates</a> on multiple occasions, and this latest report clearly shows that the risk is only getting worse. It is now more critical than ever for users to only install or update browsers and browser modules through the traditional means.</p>
<p><a class="embed-base color-body color-body-border link-embed embed-2" href="https://www.forbes.com/sites/zakdoffman/2025/02/22/apples-emergency-iphone-warning-change-whatsapp-imessage-settings/" target="_blank" aria-label="Apple’s ‘Emergency’ iPhone Warning—Change WhatsApp, iMessage Settings" rel="noopener noreferrer" data-ga-track="forbesEmbedly:https://www.forbes.com/sites/zakdoffman/2025/02/22/apples-emergency-iphone-warning-change-whatsapp-imessage-settings/"><span class="link-embed__info"><span class="link-embed__provider">Forbes</span><span class="link-embed__title">Apple’s ‘Emergency’ iPhone Warning—Change WhatsApp, iMessage Settings</span><small class="link-embed__byline">By <span class="link-embed__author">Zak Doffman</span></small></span><span class="link-embed__thumbnail-wrapper"><span class="link-embed__thumbnail allow-inline-style" style="background-image:url(https://specials-images.forbesimg.com/imageserve/65744e9437fe0bbac67751bf/960x0.jpg?cropX1=366&amp;cropX2=2108&amp;cropY1=354&amp;cropY2=1529)"/></span></a></p>
<p>Use your browser to check for updates, do not click on popups or website links however legitimate they seem. And restart your browser afterward to make sure it installs. All browsers should be set to download updates automatically. Chrome update details <a class="color-link" href="https://support.google.com/chrome/answer/95414?hl=en&amp;co=GENIE.Platform%3DDesktop" target="_blank" rel="nofollow noopener noreferrer" data-ga-track="ExternalLink:https://support.google.com/chrome/answer/95414?hl=en&amp;co=GENIE.Platform%3DDesktop" aria-label="here">here</a>.
