<p>On December 5th, we held our very first Hyperledger Web3j Summit, bringing together a vibrant cross-section of the community—from seasoned contributors and enterprise users to new enthusiasts curious about integrating Ethereum functionality into their Java and Android applications. As a maintainer of <a href="https://www.lfdecentralizedtrust.org/projects/web3j?ref=blog.web3labs.com">Hyperledger Web3j</a>, an LF Decentralized Trust project, I was excited to see participants share insights, raise important questions, and offer new ideas to drive the project forward.</p>
<h3 id="who-joined-us">Who Joined Us?</h3>
<p>The summit welcomed attendees from various backgrounds, each contributing unique perspectives:</p>
<ul>
<li><strong>Enterprise and Financial Services Developers:</strong>
<ul>
<li><strong>NTT</strong>: Shared experiences in analyzing smart contracts, monitoring on-chain events in real-time, and identifying ways Web3j can streamline financial use cases.</li>
<li><strong>Quant</strong>: Highlighted how Web3j forms a critical part of their platform to bridge multiple networks. They shared valuable feedback on exceptions, struct handling, and broader interoperability requirements.</li>
</ul>
</li>
<li><strong>Android and Mobile Innovators:</strong>
<ul>
<li><strong>FreedomFactory</strong>: Building an Android-based Ethereum OS, they rely heavily on Web3j. Their insights into performance issues, contract decoding complexities, and ENS integration were invaluable for shaping mobile-native improvements.</li>
</ul>
</li>
<li><strong>Consultants and Independent Developers:</strong>
<ul>
<li>From the UK and beyond, developers who are exploring Web3j in early or experimental phases brought fresh eyes to the project, suggesting that simplifying event handling and providing clearer documentation could lower the barrier to entry.</li>
</ul>
</li>
<li><strong>Original Author and Core Team Members:</strong>
<ul>
<li><strong>Conor Svensson (Founder of Web3j)</strong>: Provided historical context and future direction for the project’s evolution.</li>
<li><strong>Me (George Ţebrean) and Nischal Sharma (Web3 Labs): </strong>As current project maintainers, we presented the 2024 updates and longer-term roadmap and invited feedback to help us prioritize next steps.</li>
</ul>
</li>
<li><strong>Linux Foundation Decentralized Trust Support Staff:</strong>
<ul>
<li><strong>Sean Bohan (LF Decentralized Trust Staff), David Boswell (LF Decentralized Trust Staff)</strong>: Their support in organizing, moderating, and guiding the summit discussions underscored the Linux Foundation’s dedication to fostering open-source, community-driven innovation.</li>
</ul>
</li>
</ul>
<h2 id="core-impressions-and-takeaways">Core Impressions and Takeaways</h2>
<p>A few key themes emerged during the summit:</p>
<ol>
<li><strong>Improved Mobile Integration:</strong>Attendees, particularly those building native Android applications, emphasized the need for better Android ecosystem support. Performance issues with key generation and signing, integration with secure enclaves, and event handling on mobile devices were hot topics.</li>
<li><strong>Enhanced Event and Data Decoding:</strong>Users working on complex applications—such as multi-dimensional arrays in smart contract parameters, structured return types, and event logs—requested more intuitive APIs to reduce manual decoding efforts.</li>
<li><strong>Growing Importance of Interoperability:</strong>While Web3j currently focuses on Ethereum-based networks, attendees expressed interest in expanding its horizon. Ideas like support for multi-chain environments, inter-layer communication (e.g., L1 to L2), and standardized exceptions to handle various network responses emerged as potential future directions.</li>
<li><strong>Sustainable Community Engagement:</strong>Participants appreciated the existing communication channels but also suggested improvements. Ideas included labeling GitHub issues for easier onboarding (&#8220;good first issue&#8221;), exploring additional messaging platforms, and continuing regular contributor calls to maintain momentum and transparency.</li>
</ol>
<h2 id="features-and-issues-to-add-to-the-backlog">Features and Issues to Add to the Backlog</h2>
<p>During the open forum, community members raised several suggestions for enhancements. Here’s a summary of key points that we plan to evaluate and add to our backlog:</p>
<ul>
<li><strong>Event Decoding Improvements:</strong>
<ul>
<li>Provide a more straightforward mechanism for decoding events; add Java wrapper for events.</li>
<li>Add support for retrieving events by specific block ranges more easily.</li>
<li>Simplify the logic around event subscriptions and the EthLogFlowable interface.</li>
</ul>
</li>
<li><strong>Multidimensional Array and Types Support:</strong>
<ul>
<li>Implement direct support for 2D arrays and other complex data structures in smart contracts.</li>
<li>Add custom type support.</li>
</ul>
</li>
<li><strong>Android Optimization Support and Secure Key Management:</strong>
<ul>
<li>Optimize performance for key generation and signing on Android devices.</li>
<li>Consider integrating Android’s secure enclave for key storage and signing operations.</li>
<li>Improve compatibility to fully utilize features offered by the forthcoming Web3j Android modules.</li>
</ul>
</li>
<li><strong>ENS Enhancements and Generic Decoding:</strong>
<ul>
<li>Add a function input data decoder.</li>
<li>Offer a built-in utility for decoding transaction input data, reducing the reliance on third-party libraries.</li>
</ul>
</li>
<li><strong>Standardized Exception Handling and Interoperability:</strong>
<ul>
<li>Develop a more uniform approach to handle exceptions and error messages across different Ethereum networks and future L2 solutions.</li>
<li>Investigate potential support for cross-network or cross-chain functionalities.</li>
</ul>
</li>

</ul>
<h3 id="looking-ahead">Looking Ahead</h3>
<p>The first Hyperledger Web3j Summit proved that our community is both passionate and discerning. Your input helps guide our priorities and ensures that Web3j remains a valuable tool for Ethereum and broader blockchain development. We’ve taken your feedback and will incorporate these insights into our upcoming roadmap and features.</p>
<p>As we move forward, we remain committed to transparency, accessibility, and continuous improvement. Whether you’re an established enterprise team, a mobile developer building the next big DApp, or a curious newcomer, we encourage you to stay involved, contribute code, raise issues, and help shape the future of Web3j.</p>
<p>Thank you to everyone who participated and shared their experiences. {If you missed out, you can watch the summit <a href="https://www.youtube.com/watch?v=1BxsRL65jY0&amp;ref=blog.web3labs.com" rel="noopener">here</a>.} We look forward to the next summit and the collective progress we’ll achieve together.</p>
<p>To get involved with Hyperledger Web3j, check out the <a href="https://github.com/hyperledger-web3j/web3j?ref=blog.web3labs.com">Web3j Github repo</a> and join us on the <a href="https://discord.lfdecentralizedtrust.org/?ref=blog.web3labs.com">Web3j Discord channels</a>.</p>
