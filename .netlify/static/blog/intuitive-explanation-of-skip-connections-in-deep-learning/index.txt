<p>Nowadays, there is an infinite number of applications that someone can do with Deep Learning. However, in order to understand the plethora of design choices such as skip connections that you see in so many works, it is critical to understand a little bit of the mechanisms of <a href="http://neuralnetworksanddeeplearning.com/chap2.html" target="_blank" rel="noopener">backpropagation</a>.</p>
<p>If you were trying to train a neural network back in 2014, you would definitely observe the so-called <strong>vanishing gradient problem</strong>. In simple terms: you are behind the screen checking the training process of your network and all you see is that the training loss stop decreasing but it is still far away from the desired value. You check all your code lines to see if something was wrong all night and you find no clue. Not the best experience in the world, believe me!</p>

Given a learning rate of 1e-4 ( λ in the equation), you basically change the layer parameters by the product of the referenced quantities, which is 1e-19 (</p>

<p>Looking a little bit in the theory, one can easily grasp the vanishing gradient problem from the backpropagation algorithm. We will briefly inspect the backpropagation algorithm <strong>from the prism of the chain rule</strong>, starting from basic calculus to gain an insight on skip connections.</p>
<p>In short, <a href="https://en.wikipedia.org/wiki/Backpropagation" target="_blank" rel="noopener">backpropagation</a> is the “optimization-magic” behind <a href="https://theaisummer.com/Deep-Learning-Algorithms/" target="_blank" rel="noopener">deep learning architectures</a>. Given that a deep network consists of a finite number of parameters that we want to learn, our goal is to <strong>iteratively optimize these parameters with respect to the loss function L</strong>.</p>
<p>As you have seen, each architecture has some input (i.e. an image) and produces an output (prediction). The loss function is heavily based on the task we want to solve. For now, what you need to know is <strong>the loss function is a quantitative measure of the distance between two tensors</strong>, that can represent an image label, a bounding box in an image, a translated text in another language etc. You usually need some kind of supervision to compare the network’s prediction with the desired outcome (ground truth). Keep in mind that backpropagation belongs in the supervised machine learning category.</p>
<p>So, <strong>the beautiful idea of backpropagation is to gradually minimize this loss by updating the parameters of the network</strong>. But <strong>how</strong> can you propagate the scalar measured loss <strong>inside</strong> the network? That’s exactly where backpropagation comes into play.</p>
<h2 id="backpropagation-and-partial-derivatives">Backpropagation and partial derivatives</h2>
<p><strong>In simple terms, backpropagation is about understanding how changing the weights (parameters) in a network changes the loss function by computing the partial derivatives.</strong> For the latter, we use the simple idea of the chain rule, to minimize the distance in the desired predictions. In other words, backpropagation is all about <strong>calculating the gradient of the loss function</strong> while considering the different weights within that neural network, which is nothing more than calculating the partial derivatives of the loss function with respect to model parameters. By repeating this step many times, we will continually minimize the loss function until it stops reducing, or some other predefined termination criteria are met.</p>

<p>The chain rule basically describes the <strong>gradient</strong> (change) <strong>of a loss function</strong> i.e. <strong>z</strong> <strong>with respect to some neural network parameter</strong>, let’s<br />
say <strong>x</strong> and <strong>y</strong> which are functions of a previous layer parameter <strong>t</strong>. Let<br />
f, g, h be different layers on the network that perform a non-linear operation<br />
in the input vector.</p>
<div class="math">
<p>&nbsp;</p>
<p>z=f(x,y)x=g(t)y=h(t)z = f(x,y) \quad x = g(t) \quad y = h(t)<span class="katex-html" aria-hidden="true"><span class="base"><span class="mord mathnormal" style="margin-right: 0.04398em;">z</span><span class="mrel">=</span></span><span class="base"><span class="mord mathnormal" style="margin-right: 0.10764em;">f</span><span class="mopen">(</span><span class="mord mathnormal">x</span><span class="mpunct">,</span><span class="mord mathnormal" style="margin-right: 0.03588em;">y</span><span class="mclose">)</span><span class="mord mathnormal">x</span><span class="mrel">=</span></span><span class="base"><span class="mord mathnormal" style="margin-right: 0.03588em;">g</span><span class="mopen">(</span><span class="mord mathnormal">t</span><span class="mclose">)</span><span class="mord mathnormal" style="margin-right: 0.03588em;">y</span><span class="mrel">=</span></span><span class="base"><span class="mord mathnormal">h</span><span class="mopen">(</span><span class="mord mathnormal">t</span><span class="mclose">)</span></span></span></p>

<p>Interestingly, the famous algorithm does exactly <strong>the same operation but in the opposite way</strong>: it starts from the output z and <strong>calculates the partial derivatives of each parameter</strong>, expressing it only based on the gradients of the later layers.</p>
<p>It’s really worth noticing that <strong>all these values are often less than 1</strong>, independent of the sign. In order to propagate the gradient to the earlier<br />
layer’s, backpropagation uses multiplication of the partial derivatives (as in the chain rule). In general, multiplication with absolute value less than 1 is nice because it provides some sense of training stability, although there is not a strict mathematic theorem about that. However, one can observe that for every layer that we go backwards in the network <strong>the gradient of the network gets smaller and smaller</strong>.</p>
<h2 id="skip-connections-for-the-win">Skip connections for the win</h2>
<p>At present, skip connection is a standard module in many convolutional architectures. By using a skip connection, we provide an alternative path for the gradient (with backpropagation). It is experimentally validated that this additional paths are often beneficial for the model convergence. <strong>Skip connections</strong> in deep architectures, as the name suggests, <strong>skip some layer in the neural network and</strong><br />
<strong>feeds the output of one layer as the input to the next layers</strong> (instead of only the next one).</p>
<p>As previously explained, using the chain rule, we must keep multiplying terms with the error gradient as we go backwards. However, in the long chain of<br />
multiplication, if we multiply many things together that are less than one, then the resulting gradient will be very small. Thus, <strong>the gradient becomes very small</strong> <strong>as we approach the earlier layers in a deep architecture</strong>. In some cases, the gradient becomes zero, meaning that <strong>we do not update the early layers at all</strong>.</p>
<p>In general, there are two fundamental ways that one could use skip connections through different non-sequential layers:</p>
<p>a) <strong>addition</strong> as in residual architectures,</p>
<p>b) <strong>concatenation</strong> as in densely connected architectures.</p>
<p>We will first describe addition which is commonly referred as residual skip connections.</p>
<h2 id="resnet-skip-connections-via-addition">ResNet: skip connections via addition</h2>
<p>The core idea is to backpropagate through the identity function, by just using a vector addition. Then the gradient would simply be multiplied by one and its value will be maintained in the earlier layers. This is the main idea behind Residual Networks (ResNets): they stack these skip residual blocks together. We use an identity function to <strong>preserve the gradient</strong>.</p>

<p>Apart from the vanishing gradients, there is another reason that we commonly use them. For a plethora of tasks (such as semantic segmentation, optical flow estimation , etc.) there is some information that was captured in the initial layers and we would like to allow the later layers to also learn from them. <strong>It has been observed that in earlier layers the learned features correspond to lower semantic information that is extracted from the input.</strong> If we had not used the skip connection that information would have turned too abstract.</p>

The most famous deep learning architecture is <a href="https://arxiv.org/abs/1608.06993" target="_blank" rel="noopener">DenseNet</a>.  Below you can see an example of feature resusability by concatenation with 5 convolutional layers:</p>

<p>b) to more <strong>compact</strong> models, and</p>

<h2 id="short-and-long-skip-connections-in-deep-learning">Short and Long skip connections in Deep Learning</h2>
<p>In more practical terms, you have to be careful when introducing additive skip connections in your deep learning model. <strong>The dimensionality has to be the same</strong> <strong>in addition and also in concatenation apart from the chosen channel dimension</strong>. That is the reason why you see that additive skip connections are used in two kinds of setups:</p>
<p>a) <strong>short </strong>skip connections</p>
<p>b) <strong>long </strong>skip connections.</p>
<p>Short skip connections are used along with consecutive convolutional layers that do not change the input dimension (see <a href="https://arxiv.org/abs/1512.03385" target="_blank" rel="noopener">Res-Net</a>), while long skip connections usually exist in encoder-decoder architectures. It is known that the <strong>global information</strong> (shape of the image and other statistics) <strong>resolves what</strong>, <strong>while local information resolves where</strong> (small details in an image patch).</p>
<p>Long skip connections often exist in architectures that are symmetrical, where the <strong>spatial dimensionality is reduced in the encoder part</strong> and is gradually increased in the decoder part as illustrated below. In the decoder part, one can increase the dimensionality of a feature map via <a href="https://www.machinecurve.com/index.php/2019/09/29/understanding-transposed-convolutions/" target="_blank" rel="noopener">transpose convolutional layers</a>. The transposed convolution operation forms the same connectivity as the normal convolution but in the backward direction.</p>
<h2 id="u-nets-long-skip-connections">U-Nets: long skip connections</h2>
<p>Mathematically, if we express convolution as a matrix multiplication, then transpose convolution is the reverse order multiplication (BxA instead<br />
of AxB). The aforementioned architecture of the encoder-decoder scheme along with long skip connections is often referred as U-shape (<strong>Unet</strong>). It is<br />
utilized for tasks that the prediction has the same spatial dimension as the input such as <a href="https://theaisummer.com/Semantic_Segmentation/" target="_blank" rel="noopener">image segmentation</a>, optical flow estimation, video prediction, etc.</p>
<p><strong>Long skip connections can be formed in a symmetrical manner</strong>, as shown in the diagram below:</p>

<p>By introducing skip connections in the encoder-decoded architecture, <strong>fine-grained details can be recovered in the prediction</strong>. Even<br />
though there is no theoretical justification, symmetrical long skip connections work incredibly effectively in dense prediction tasks (<a href="https://theaisummer.com/medical-image-deep-learning/" target="_blank" rel="noopener">medical image segmentation</a>).</p>
<h2 id="conclusion">Conclusion</h2>
<p>To sum up, the motivation behind this type of skip connections is that they have an uninterrupted gradient flow from the first layer to the last layer, which tackles the vanishing gradient problem. Concatenative skip connections enable an alternative way to ensure <strong>feature reusability</strong> of the same dimensionality from the earlier layers and are widely used.</p>
<p>On the other hand, <strong>long skip connections are used to pass features from the encoder path to the decoder path in order to recover spatial information lost during downsampling</strong>. Short skip connections appear to stabilize gradient updates in deep architectures. Finally, <strong>skip connections enable feature reusability and stabilize training and convergence.</strong></p>
