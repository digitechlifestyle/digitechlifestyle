<p class="duet--article--dangerously-set-cms-markup duet--article--standard-paragraph _1ymtmqpi _17nnmdy1 _17nnmdy0 _1xwtict1">Google Photos is adding its digital SynthID watermarks to photos that have been edited using the Magic Editor’s generative AI feature. The new feature is <a href="http://blog.google/feed/synthid-reimagine-magic-editor">rolling out “this week” according to Google</a>, and is intended to make it easier for people to quickly identify images that have been manipulated using the “reimagine” tool in Magic Editor.</p>
</div>
<div>
<p class="duet--article--dangerously-set-cms-markup duet--article--standard-paragraph _1ymtmqpi _17nnmdy1 _17nnmdy0 _1xwtict1"><a href="https://www.theverge.com/2023/8/29/23849107/synthid-google-deepmind-ai-image-detector">SynthID</a> is a watermarking system created by Google’s DeepMind team that embeds a digital metadata tag directly into images, video, audio, and text to identify if they were created or altered using AI tools. The watermark is already being applied to images that are entirely AI-generated using Google’s Imagen text-to-image model. Similar watermarking systems have also been developed by other companies, like the <a href="https://www.theverge.com/2023/10/10/23911381/adobe-ai-generated-content-symbol-watermark">Content Credentials that Adobe applies</a> to works created or edited using its suite of Creative Cloud apps.</p>
</div>
<div>
<p class="duet--article--dangerously-set-cms-markup duet--article--standard-paragraph _1ymtmqpi _17nnmdy1 _17nnmdy0 _1xwtict1">That’s a problem the new watermarking update is attempting to solve, but there are a few issues. For one, SynthID doesn’t visibly alter the image it’s attached to and can be identified using a <a href="https://blog.google/products/search/google-about-this-image-update-july-2024/#:~:text=enhanced%20by%20AI.-,Digital%20watermark%3A,-About%20this%20image">dedicated AI detection tool</a> that’s a part of Google’s <a href="https://blog.google/products/search/google-about-this-image-update-july-2024/">“About this image” feature</a>. Google also says that some edits made using the Magic Editor reimagine “may be too small for SynthID to label and detect.” </p>
</div>
<div>
<p class="duet--article--dangerously-set-cms-markup duet--article--standard-paragraph _1ymtmqpi _17nnmdy1 _17nnmdy0 _1xwtict1">While watermarking tech can help if it <em>does</em> catch manipulations, some experts in this field agree that <a href="https://www.theverge.com/2023/10/31/23940626/artificial-intelligence-ai-digital-watermarks-biden-executive-order">watermarking alone won’t be effective enough</a> to reliably authenticate AI-generated content at scale, and will require a varied suite of different approaches working in tandem.</p>
</div>
